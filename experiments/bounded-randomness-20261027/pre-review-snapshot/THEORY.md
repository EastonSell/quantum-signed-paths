# Fixed randomness, conditional on an exact probability oracle
For a basis-input H/Toffoli circuit with h Hadamards, every output amplitude is an integer times 2^(-h/2). Thus every output probability and every prefix probability is a nonnegative integer multiple of 2^(-h). Define M(p)=2^h P(p). Then M(empty)=2^h and M(p)=M(p0)+M(p1).

Draw exactly h independent fair bits, interpreted as a uniform integer R in [0,2^h). Maintain a prefix p and a relative rank r in [0,M(p)). Query M(p0). If r<M(p0), extend p by zero. Otherwise subtract M(p0) and extend p by one. This partitions the parent interval into adjacent child intervals of their exact integer masses. Induction gives precisely M(y) initial ranks ending at output y. Hence its probability is M(y)/2^h=P(y). Zero-mass branches are never entered. Empty registers and h=0 obey the same invariant.

The implemented sampler makes exactly n left-prefix oracle calls and exactly h calls to the supplied bit source. The fair-bit assumption includes independence; the program checks bit values but cannot verify their distribution. All rank arithmetic uses at most h+1 bits, and the stored prefix has n bits. Excluding the oracle, auxiliary space is O(n+h) bits mathematically (Python objects have overhead). Tuple prefix construction takes O(n^2) aggregate copying; integer arithmetic adds polynomial overhead. Input validation and gate counting add polynomial input cost. There is no claim that h is the smallest possible bit budget: identity HH wastes two bits, while its deterministic output needs zero.

This closes only the fixed worst-case randomness gap in the earlier sampler. The old sequential conditional sampler uses exact rational conditionals and integer rejection sampling, which has expected finite random-bit cost but no finite worst-case cap. Both use n prefix queries; this method does not reduce the dominant oracle complexity. The default reference oracle stores 2^h paths and scans ordered pairs: exponential time and space remain. A replacement oracle with time T and space S gives n oracle calls, polynomial overhead, and space S+poly(n+G), provided each call returns an exact probability. No such improved oracle is implemented or independently established here. The upstream subexponential-counting claim remains conditional and unverified by this artifact.

This is standard integer inverse-CDF sampling expressed as a prefix tree, already proposed in the parent THEORY.md. It is not a new sampling theorem or quantum advantage.
